Core Concepts & Formulas

1. Methods to Find Mean (x̄)

Direct Method:

x̄ = ∑fᵢxᵢ / ∑fᵢ

Assumed Mean Method:

x̄ = a + (∑fᵢdᵢ / ∑fᵢ)

Where dᵢ = xᵢ - a

Step-Deviation Method:

x̄ = a + h × (∑fᵢuᵢ / ∑fᵢ)

Where uᵢ = (xᵢ - a) / h

2. Median of Grouped Data

Median = l + [ ((n / 2) - cf) / f ] × h

3. Mode of Grouped Data

Mode = l + [ (f₁ - f₀) / (2f₁ - f₀ - f₂) ] × h

4. Empirical Relationship

Mode = 3(Median) - 2(Mean)

Points to Remember

Empirical Relationship: A key formula connecting all three measures of central tendency: Mode = 3 Median - 2 Mean.
Class Mark: For grouped data, the mid-point of a class interval (class mark xᵢ) is calculated as (Upper Class Limit + Lower Class Limit) / 2.

Important Practice Questions

  1. Find the mean of a given frequency distribution using the step-deviation method.
  2. Calculate the median for a grouped frequency distribution table.
  3. Find a missing frequency in a given data set when either the mean or median is provided.
